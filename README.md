# DOTSTO
## Les premières tâches : 
- Faire une page avec des flottes fictives
- Faire un design immersive 3D
- Au scroll, la flotte doit être animé (rotateY)

### Contenu de la page "flotte" :
- Plaque d’immatriculation
- Marque
- Modèle
- Année
- Indication de l’état du véhicule par couleur
- Eco-score de la flotte (0-100)
    - Pourquoi ce score ?
        - Contrôle technique
        - Assurance
        - Entretien
- Bouton CTA "Planifier le contrôle technique" et "Voir les actions recommandées"


## Exigences globale de DOTSTO :
- Conformité du véhicule
- Risque de panne
- Coût au cours des 12 prochains mois
- Quand le réparer, le remplacer ou le vendre.
